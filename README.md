# Smart City Health Highway

An integrated smart healthcare platform designed to connect patients, doctors, healthcare services, and emergency assistance through a single digital system.

## Features

* AI-powered healthcare assistance
* Patient and doctor services
* Patient health records management
* Doctor appointments
* Emergency ambulance tracking
* Smart healthcare management
* User-friendly web interface

## Getting Started

### 1. Clone the repository

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
cd smart-city-health-highway
```

### 2. Install dependencies

For the frontend:

```bash
cd client
npm install
```

For the backend:

```bash
cd ../server
npm install
```

### 3. Configure environment variables

Create a `.env` file inside the `server` directory and add the required configuration values.

> Do not commit `.env` files or other sensitive credentials to GitHub.

### 4. Run the project

Start the backend:

```bash
cd server
npm start
```

Start the frontend in another terminal:

```bash
cd client
npm run dev
```

The Smart City Health Highway aims to provide a centralized digital healthcare ecosystem where users can access healthcare assistance, manage medical information, connect with doctors, schedule appointments, and receive emergency support.
